\begin{cnabstract}
本文对 pr3967-combined 分支为 LingBot-VLA 2.0 引入的全部优化开关做\textbf{逐项真机启动验证}:
训练开关经 \texttt{lerobot-train} 真实启动(steps=3、gpudad SO101 真实数据集),
推理开关经 ckpt 加载与 \texttt{predict\_action\_chunk}(rollout 的策略路径),
另设一臂完整复刻 rollout 加载方式(开关固化进 \texttt{config.json} 后 \texttt{from\_pretrained})。
共 13 臂,\textbf{11 臂通过};两臂给出负面结论——\texttt{EFFICIENT\_ATTENTION} 后端直接无可用 kernel,
\texttt{CUDNN\_ATTENTION} 能启动但第一个训练步梯度即 NaN。
最终纪律一句话:\textbf{\texttt{sdpa\_backend} 整体不要设,自动后端是唯一安全且最优的选择}。
\end{cnabstract}
\keywords{LingBot-VLA 2.0;开关验证;lerobot-train;lerobot-rollout;SDPA 后端}

\section{引言}
本分支相对上游 PR \#3967 引入了一组训练/推理优化开关。开关表不能只靠读代码核对:
\texttt{sdpa\_backend} 一类开关``能解析、能启动''与``训练可用''之间隔着真实的数值缺陷。
本文回答的问题是:\textbf{每一个开关,真启动能不能起来?起来之后数值对不对?}

\section{验证设置}
验证矩阵驱动脚本 \texttt{bench/run\_switch\_smoke.sh},产物在 A100 侧
\texttt{\textasciitilde/accel-bench/}\allowbreak\texttt{switch\_smoke/} 目录。权重为 robotwin 6B 转换 ckpt,
数据集 gpudad SO101(993 段 / 132k 帧 / 3 相机 512$\times$512)。
宿主机 GPU 0--3 被 LIBERO eval 占用,本矩阵全程跑在 GPU 4--7。

\textbf{训练臂}(每臂独占一卡):\texttt{lerobot-train} 启动,steps=3、batch\_size=1、
num\_workers=2、\texttt{save\_checkpoint=}\allowbreak\texttt{false},其余与手册标准命令一致。
判据:exit 0 且 3 步 loss 有限、与对照组一致。

\textbf{推理臂}:\texttt{bench/bench\_lingbot\_v2.py infer}(iters=3, warmup=1),
即 \texttt{from\_pretrained} + 合成观测 + \texttt{predict\_action\_chunk}。
I6 为 rollout 完整路径复刻:五个推理开关固化进 \texttt{config.json} 副本后从头加载。

\section{讨论}
两个负面结果都来自真启动而非代码阅读:\texttt{EFFICIENT\_ATTENTION} 在加载后第一次
attention 调用即报无可用 kernel;\texttt{CUDNN\_ATTENTION} 的 NaN 只在 backward 出现,
前向 parity 检查(rel diff $3.3\times10^{-7}$)完全无法发现。
后端切换类开关的验收门槛因此定为\textbf{多步 e2e 训练},单步前向对比不足为据。
\texttt{sdpa\_backend} 保留在配置里仅供调试,生产命令一律不写。

另有一次反向教训:合成 bench(相同样本平铺、序列短且定长)曾显示 eager+bf16 训练
更快更省(-6.9\%、-10GB),据此一度准备改默认;300 步真实数据集 A/B(2026-08-14,
loss 曲线完全等价)推翻了它——真实变长序列下 eager 稳态 +2.2\% 慢、+2.9GB、B=4 OOM。
\textbf{bench 结论迁移到真实训练前必须用真实数据复核},sdpa+bf16 维持推荐默认。

\section{结论}
13 臂矩阵,11 臂通过、2 臂给出禁用级证据。推荐组合不变:
\textbf{训练}全默认 + \texttt{optimizer\_fused=}\allowbreak\texttt{true},单卡 B=3 / 多卡 B=2 每卡;
\textbf{推理}五开关固化进 \texttt{config.json}(e2e 436 ms @ robotwin 3 相机,
约 300 ms @ 单相机)。\textbf{\texttt{sdpa\_backend} 一律不设。}
